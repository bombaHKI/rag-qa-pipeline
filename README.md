# RAG Q&A Pipeline

A Retrieval-Augmented Generation (RAG) application that answers questions using Simple English Wikipedia as its knowledge base. The pipeline retrieves relevant passages, re-ranks them for precision, and generates fluent answers using a pretrained language model — all running locally with no paid APIs.
